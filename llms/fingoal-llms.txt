# FinGoal

> FinGoal provides financial data insights for banks, credit unions, and fintechs. The Insights API enriches raw transaction data with clean merchant names, categorization, and FinGoal Persona Tags, and pushes updated user tags and enrichment results via webhooks. Link Money is a separate authentication portal in front of a shared Yodlee aggregation instance, used to link and verify accounts across 17,000+ financial institutions. Both APIs authenticate with a JWT minted from client credentials; there is no self-serve signup - developer credentials are issued on reviewed request.

## APIs

- [Insights API docs](https://docs.fingoal.dev/): Transaction enrichment, user tags, and webhook configuration. Base URLs: https://findmoney-dev.fingoal.com/v3 (dev), https://findmoney.fingoal.com/v3 (prod).
- [Link Money docs](https://link-money-docs.fingoal.dev/): Account aggregation and verification. Base URL: https://link-money-dev.fingoal.dev/api (only host published). Proxies the Yodlee Core API.

## Specs

## Insights API operations

- syncCleanupTransactions - POST /cleanup/sync - Test (synchronous) transaction enrichment
- asyncCleanupTransactions - POST /cleanup - Historical (async) transaction enrichment
- streamingCleanupTransactions - POST /cleanup/streaming - Streaming transaction enrichment
- baseCleanupTransactions - POST /cleanup/base - Base transaction enrichment
- getEnrichment - GET /cleanup/{batch_request_id} - Retrieve enrichment by batch request id
- getOneUser - GET /users/{userId} - Get a user
- getOneUserSync - GET /users/{userId}/sync - Trigger a user tag update
- getUserTagUpdates - GET /users/tags/{guid} - Retrieve updated tags
- listWebhookConfigurations - GET /webhook-configurations
- upsertWebhookConfiguration - PUT /webhook-configurations
- deleteWebhookConfiguration - DELETE /webhook-configurations
- testWebhook - POST /webhook-configurations/test

## Link Money API operations

- oauthToken - POST /oauth/token - Obtain a tenant-scoped access token
- getClient - GET /client - View your client configuration
- getWebhooks - GET /client/webhooks - List configured webhooks
- createWebhook - POST /client/webhooks - Enable a new webhook
- getWebhook - GET /client/webhooks/{webhookId} - Retrieve a webhook
- updateWebhook - PATCH /client/webhooks/{webhookId} - Update a webhook
- deleteWebhook - DELETE /client/webhooks/{webhookId} - Delete a webhook
- fireTestWebhook - POST /client/webhooks/{webhookId}/fire_test_webhook - Trigger a test webhook
- getFastlinkFourDetails - POST /yodlee/fastlink/get - Retrieve Yodlee FastLink 4 session details

## Authentication

- Insights API: POST https://findmoney.fingoal.com/v3/authentication with {"client_id","client_secret"} returns a JWT access_token valid 86400s. OAuth2 scopes: enrichment, read, calls_to_action.
- Link Money: POST https://link-money-dev.fingoal.dev/api/oauth/token with {"clientId","clientSecret","tenantId"} returns {"token"}, valid 1 hour and scoped to a single tenant.
- Both: send Authorization: Bearer <token>.

## Events

- Insights webhooks: ENRICHMENT_DATA, ENRICHMENT_NOTIFICATION, USER_TAGS_DATA, USER_TAGS_NOTIFICATION, INSIGHTS. Each delivery carries an X-Webhook-Verification SHA-256 HMAC header.
- Link Money webhooks: DATA_UPDATES, REFRESH, AUTO_REFRESH_UPDATES, LATEST_BALANCE_UPDATES, CDV_STATUS_UPDATES, OB_CONSENT, OB_ACTIVE_CONSENT_REMINDER.

## Known gaps

- No pricing page (https://fingoal.com/pricing returns 404); commercial terms are sales-negotiated.
- No status page (status.fingoal.com does not resolve), no SLA, and no dated changelog.
- No first-party SDKs on npm, PyPI, RubyGems or crates.io.
- No published rate limits or rate-limit response headers; only per-request payload sizing guidance.
- No MCP server and no A2A agent card.
